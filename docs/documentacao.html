Sistema de Login Seguro

1 Introdução

Este documento explica, de forma simples, o sistema de login da atividade. A pessoa cria uma conta, entra com o e-mail e a senha e, quando quiser, pode sair. Cada usuário acessa as páginas do seu perfil.

2 Objetivo

O sistema foi feito com Java, Spring Boot, Spring Security, Thymeleaf e MongoDB. Há três perfis: ADMIN, PROFESSOR e ALUNO. As páginas e os estilos ficam em arquivos separados. Assim, dá para mudar o visual sem mexer nas regras de login.

3 Estrutura do sistema

O código Java está separado por pastas. Os controladores recebem as ações das páginas. Os serviços fazem o cadastro e procuram usuários. O repositório acessa o banco, e o modelo representa uma conta. As páginas HTML ficam nos templates e o CSS fica em outra pasta.

Uma conta nova começa como ALUNO. O administrador pode mudar o perfil de outra pessoa ou excluir a conta. Para não perder o acesso, não pode excluir a própria conta nem o último administrador. Quando o perfil muda ou uma conta é apagada, as sessões daquela pessoa também são encerradas.

A primeira conta de administrador é criada pelas variáveis ADMIN_EMAIL e ADMIN_PASSWORD, se elas forem configuradas. Assim, a senha não precisa ficar escrita no código.

4 Integração com MongoDB Atlas

Para conectar ao Atlas, crie um usuário do banco, libere o IP do computador e copie a URI de conexão. Coloque essa URI na variável MONGODB_URI. Não publique usuário e senha no GitHub.

As contas ficam na coleção usuarios, e as sessões ficam na coleção sessoes. Também dá para testar com um MongoDB local.

5 Segurança e decisões de design

O Spring Security cuida do login e limita cada página ao perfil correto. O BCrypt transforma a senha em um hash antes de ela ser salva. O cadastro também confere nome, e-mail e tamanho da senha. A proteção CSRF dos formulários continua ligada.

As páginas usam Thymeleaf. A variável APP_TEMA escolhe o arquivo CSS. Se quiser mudar as cores, basta criar outro arquivo de estilo. Quando o sistema for publicado, use HTTPS e uma senha forte para o banco.

6 Execução e adaptação

Para rodar o projeto, instale o JDK 17 e o Maven, configure MONGODB_URI e, no terminal dentro da pasta do projeto, execute mvn spring-boot:run. Depois abra http://localhost:8080 no navegador.

Para adaptar o projeto a outro tema, troque os textos das páginas e os arquivos CSS. O cadastro, o login e as permissões continuam separados do visual.
